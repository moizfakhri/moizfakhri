# Moiz Fakhri

I study industrial engineering and data science at Georgia Tech. I work with Python and SQL to build forecasting models, geospatial data pipelines, and tools people can use to explore the results.

My research at Georgia Tech supports sidewalk accessibility and wheelchair routing in Atlanta. At Invesco, I tested which economic and market signals improved forecasts of real estate returns.

[Website](https://www.moizfakhri.com/) · [LinkedIn](https://www.linkedin.com/in/moizfakhri/)

## Selected work

- [**Silent Buildings**](https://github.com/moizfakhri/Silent-Buildings) — Tested whether a lack of tenant complaints masks housing risk across 101,442 NYC residential buildings. The LightGBM model beat a prior-violations baseline in all 16 out-of-time evaluations. The repository includes the analysis and a 3D map.
- [**ReMeet**](https://github.com/moizfakhri/ReMeet) — Built a Swift app that records meetings on macOS, transcribes audio on-device, and links notes and summaries back to the recording.
